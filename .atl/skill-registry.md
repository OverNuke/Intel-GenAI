## Compact Rules (project standards)

- Hexagonal by module: `src/modules/<m>/{domain,application,infrastructure,ui}`; `domain` imports no Next/Drizzle/AI SDK.
- The human confirms: assistant port exposes no submit/close; `submitTicket` requires `by: "human"` from the requester.
- Strict TDD: failing test first (Vitest), minimum code, then refactor.
- UI copy es-MX plain language; code/docs/commits in English. Tokens from `src/ui/tokens.css`; themes via `[data-theme]`.
- Metrics: measured and estimated are distinct types; estimates labelled "no son resultados medidos".
- Conventional commits, no Co-Authored-By/AI attribution. No build after changes. Use rg/fd/bat/eza.
- pnpm `minimumReleaseAge` blocks very recent releases: pin older versions.
